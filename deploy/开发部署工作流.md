## 日常迭代（改前端）

```bash
npm run dev          # 本地调试，Vite 会自动拉起本地网易云 API
# 改代码……
git add -A
git commit -m "feat: xxx"
git push
```

push 之后 GitHub Actions 自动完成：`npm ci` → `npm run build` → FTP 增量同步 `dist` 到站点根目录。
约 1–2 分钟后刷新线上即可（记得 `Ctrl+F5`，`index.html` 不缓存但浏览器偶尔会留旧页）。

**不需要**再手动 `npm run build`、打 zip、上传、解压。

## 首次配置（只做一次）

### 1. 拿到 FTP 信息

cPanel → **FTP Accounts**，可以直接用 cPanel 主账号：

| 项 | 从哪来 |
| --- | --- |
| `FTP_SERVER` | `ftp.131202914.xyz` 或主机 IP（cPanel 首页 Shared IP） |
| `FTP_USERNAME` | cPanel 用户名，例如 `fjctduyeao` |
| `FTP_PASSWORD` | 该账号密码 |
| `FTP_SERVER_DIR` | `/131202914.xyz/`（FTP 登录后的相对根目录） |

### 2. 配置 GitHub Secrets

仓库 → **Settings → Secrets and variables → Actions → New repository secret**，依次添加：

```
FTP_SERVER
FTP_USERNAME
FTP_PASSWORD
FTP_SERVER_DIR
```

### 3. 触发第一次部署

推任意一个提交，或到 **Actions → Deploy to Spaceship → Run workflow** 手动跑一次。

成功后 Actions 日志里能看到上传了哪些文件。

> ⚠️ `deploy.yml` 里 `dangerous-clean-slate` 必须保持 `false`。
> 站点根目录下还有 `.htaccess` 和 `netease-api/`，开启清空会把它们一起删掉，站点直接挂。

## 改 API 的流程（不走 CI）

API 目录里有 `node_modules`，不能全量同步，所以单独处理：

- **只改了 `app.js` / `server.js`**：用 `deploy/netease-api-patch/` 里的版本，File Manager 覆盖到 `131202914.xyz/netease-api/`，然后 cPanel → Setup Node.js App → **Restart**
- **改了 `package.json`（依赖变化）**：在 Terminal 里

  ```bash
  source /home/fjctduyeao/nodevenv/131202914.xyz/netease-api/18/bin/activate
  cd /home/fjctduyeao/131202914.xyz/netease-api
  npm install --omit=dev --ignore-scripts
  ```

  再 Restart。`--ignore-scripts` 是绕开 `prepare: husky install`，服务器上没有 .git 会失败。

## 排查入口

| 现象 | 先看哪 |
| --- | --- |
| Actions 红叉 | 点进 run 看哪个 step 失败，通常是 `npm ci` 或 FTP 认证 |
| 部署成功但页面没变 | 浏览器强刷；或看 FTP 日志里 `index.html` 是否真的上传了 |
| 页面白屏 | F12 Console 看是不是资源 404（`assets` 没传全） |
| 接口 502/503 | cPanel → Setup Node.js App 看应用是否 Running；Restart 一次 |
| 接口 404 | `.htaccess` 的 `PassengerBaseURI` 或 `RewriteRule ^api` 被改动了 |
